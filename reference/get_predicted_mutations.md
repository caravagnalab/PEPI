# Get posterior-predictive mutation counts (m\_\*\_pred) with observed counts joined in.

Get posterior-predictive mutation counts (m\_\*\_pred) with observed
counts joined in.

## Usage

``` r
get_predicted_mutations(x)
```

## Arguments

- x:

  PEPI_Multirates object, after
  [`get_posterior_multirates()`](https://caravagnalab.github.io/PEPI/reference/get_posterior_multirates.md).

## Value

A tibble with posterior mean/95

## Examples

``` r
if (FALSE) { # \dontrun{
get_predicted_mutations(x)
} # }
```
