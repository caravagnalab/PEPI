# R version of the Stan approx_Z(), vectorised over posterior draws.

R version of the Stan approx_Z(), vectorised over posterior draws.

## Usage

``` r
.approx_Z(lambda_n, lambda_p, omega_n, omega_p, t_1, t_2, W1, chi)
```

## Value

A list with the "-" (\`neg\`) and "+" (\`pos\`) population sizes.
