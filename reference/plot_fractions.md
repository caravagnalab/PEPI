# Plot predicted vs observed fractions for the unified multirates model.

Faceted by group/id and epistate, using
[`get_predicted_fractions()`](https://caravagnalab.github.io/PEPI/reference/get_predicted_fractions.md).

## Usage

``` r
plot_fractions(x)
```

## Arguments

- x:

  PEPI_Multirates object, after
  [`get_posterior_multirates()`](https://caravagnalab.github.io/PEPI/reference/get_posterior_multirates.md).

## Value

Plot of predicted vs observed fractions.

## Examples

``` r
if (FALSE) { # \dontrun{
plot_fractions(x)
} # }
```
