# Get posterior-predictive fractions (frac\_\*\_pred) with observed fractions joined in.

Get posterior-predictive fractions (frac\_\*\_pred) with observed
fractions joined in.

## Usage

``` r
get_predicted_fractions(x)
```

## Arguments

- x:

  PEPI_Multirates object, after
  [`get_posterior_multirates()`](https://caravagnalab.github.io/PEPI/reference/get_posterior_multirates.md).

## Value

A tibble with posterior mean/95

## Examples

``` r
if (FALSE) { # \dontrun{
get_predicted_fractions(x)
} # }
```
