# Associate colors to nodes.

A list of colors labelled by nodes is generated.

## Usage

``` r
get_colors(max_depth)
```

## Arguments

- max_depth:

  Maximal number of levels of the tree

## Value

Named list of colors.

## Examples

``` r
if (FALSE) { # \dontrun{
get_colors(max_depth = 2)
} # }
```
